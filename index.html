Recent Work

RPG Pet Project

A literal pet project mobile game I made. Level your pets and see them fight against enemies and bosses. Made in Unity it was created as a side project to learn how to create a unique idle battler with monster training functions and a shop. Created with much love and a lot of different iterations.

Dog Knight: Adventure

First major project with schoolmates. Action RPG with levelling, spells and a final boss. I created the enemy system and talent system and optimized the performance so the game could handle large amount of enemies using scriptable objects and a backend enemy handler. The implementation of saving the talents and leveling system for further use was made. The talent tree was made so it needed prerequisites in order to level further stats.

Frog Crawl

Frog Crawler. You fight frogs with a classic ps1 action RPG feel. Experimented with simulating PS1 shaders into Unity.

Gromp

Sokoban style puzzle mobile game where you can place and kick boxes. Using swipe controls, saving system and introducing new features for the player to learn throughout the game.

All in Vania

2D Platformer with Castlevania gameplay mechanics. Made with C# and Unity. The main goal was to create the same feel as you had in the old school Castlevania games.

Doomquake Prototype

Fastpaced survival shooter with "Devil Dagger" inspiration. Made under two days as a challange. Used Blender and Unity.
